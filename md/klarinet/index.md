# Klarinet

Modro označena so tipke, rdeče pa odprtine. Povezave med tipkami in zaklopkami
(ki zapirajo odprtine) so označene s sivimi črtami; vijolične puščice pa stojijo
tam, kjer je povezava enosmerna, torej deluje le v smeri puščice.

Klarinet je sestavljen iz štirih večjih delov (označeni črno):

- ustnik (nanj je še z objemko pritrjen enojni jeziček)
- sodček
- zgornji del trupa (leva roka)
- spodnji del trupa (desna roka)
- odmevnik
