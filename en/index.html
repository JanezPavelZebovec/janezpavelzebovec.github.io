Site index

  • High Slovenian (Visoka slovenščina – what Slovenian should be (or has to be)

  • Astronomical clock – visualisation of space as clock
    • Notes to Astronomical clock
  • Phonetic script (Glasopisnica) – my own constructed phonetic script (I am still working on it – on script as well as webpage)
  • My family tree – my family tree on which I work with my cousin (with focus on ancestors; because of privacy, only first and last names are visible for living individual and those who died in last 20 years)
  • Software – presentation of (my) ideology about good software and list od good software
    • My Linux – guide thorugh installation and setting of operation system as mine
  • Diary – logging of progress at various projects, listed only more important milestones
  • Map – set of some open maps, majority of which are just different styles of OpenStreetMap data, there is also GURS imagery, and prohibited G***le Maps just for comparision
  • My lists – recomendations, intersting webistes and other lists, manly of web links
  • Thinking – set of citations, data and my thoughts on current political questions (page is very much in early stage of creation, subjects are presented very shallowy and one-sidedly)

There is also my Library, where some areas of my knowledge/education are put together, therefore nonoriginal stuff that you can read elsewhere.

This website is in majority written in Markdownu and then converted to HTML with Pandocom, that is why pages are also accessible in original Markdown format in section janezpavelzebovec.net/md/. In footer of each page is link to it’s page in Markdown.

Date of last page change at the top takes in account only content-related changes, not stylistic or minor (grammar) fixes.

I use coloscheme Gruvbox by Pavel Pertsev.

Page My family tree is created with Gramps.

Website analitycs are accessible at Umami. Somewhere March 2026 I banned access for bots. Traffic has been greately reduced because of that,

Website has 3 shortcuts:

  • B – toggle color theme (dark/light)
  • D – homepage
  • M – page in Markdown format

Guidelines

  • as simple as possible, but not at the expense of beauty and usability;
  • as little JavaScript as possible (i.e., animations, transitions, interactivity, etc.; the website must function even without it – with the exception of Astronomical clock, of course);
  • HTML structure that allows for a clear view of the page even without CSS, or allows for easy adaptation to one’s own style;
  • content should also be accessible as plain text (e.g., for viewing in a terminal)— see the janezpavelzebovec.net/md/ section)
